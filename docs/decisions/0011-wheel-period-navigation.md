# 0011：滚轮缩放与展示周期联动

日期：2026-10-27；版本4.3.0。

## 需求与行为

用户明确要求滚轮放大自动进入细周期、缩小返回、保持正在查看的时间位置，并明确提示缺失行情。原先只有图形放大和按钮下钻。

默认开启，可关闭。自动周期阶梯月/周/日/60m/30m/5m/1m，跳过A股一天一根的4h；手动4h进入60m时，缩小仍返回4h。无历史路径时缩小进入相邻粗周期；最细/最粗边界提示后继续普通缩放。

主图、MACD共用滚轮导航与逻辑时间轴。以鼠标所指真实K线作为锚，记录横向比例。目标显示范围按当前可见真实K线覆盖时间寻找，再按锚点比例定位。分钟桶采用(end-duration,end]，保留日内边界；粗周期按日历桶展开到最后可用子K线。不把日、周、月蜡烛误称为已证明的递归结构层。

进入细周期阈值70px/根；进入粗周期阈值7px/根，或从自动下钻后的初始可见根数扩大到1.5倍。300ms内连续滚动算同一手势，最多切一级；加载中不重复请求。缺失锚点/失败按方向与锚点日期抑制重复请求，数据刷新后解除。参数集中在wheelNavigation.ts，属于展示交互参数，不是缠论参数。

## 数据、规则与边界

请求完整本地目标周期历史（不联网同步），以独立视窗保留位置，避免下钻裁剪后缩小困在窗口内。继承实际basePeriod/maxLevel，R01/R02/R03及所有算法不变。空行情、锚点时间缺口不跳到其他日期；不补造价格、不静默跳过缺数据的周期。只有请求成功且存在锚点覆盖才修改周期、历史路径和数据。API失败保留原图。各数据源、复权口径和既有历史长度限制仍然存在。

规则版本按保护要求升级；固定样本只修改版本元数据，不更改几何预期。新增纯函数回归与真实行情无头浏览器验证脚本scripts/verify_wheel_navigation.cjs；并回归原有按钮区间下钻。


## 验证结果

- 112个后端测试、14个前端测试、前端构建及变更守卫通过。原有按钮区间导航11阶段回归通过。
- 真实立讯精密本地行情验证日K→60m→30m及MACD缩小返回日K。目标画布OHLC/MACD逐项等于对应API数据；两窗时间轴与横坐标一致（0px），鼠标锚点切换误差≤0.25px，来自鼠标像素取整。
- 连续滚轮手势只发一个周期请求；关闭自动切换后只缩放；8月缺失5m时保留30m全套画布数据且抑制重复请求；503错误保留原图。1m/月K边界提示且不发额外请求。
- 7份相同输入的全量快照对比，除analysis版本/批次等元信息外，所有分析字段不变；未修改原始行情，未注入模拟价格。
- 证据位于docs/research/wheel-navigation-20261027-{render,comparison,button-regression}.json。
- 空白边距和仅有结构端点的时刻不触发周期切换，不能把鼠标指向的空白位置改成远处真实K线。
