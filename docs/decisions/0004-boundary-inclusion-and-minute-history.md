# 0004：修复转折边界包含及5m历史不足

状态：接受。版本：4.0.1。日期：2026-09-30。

用户看到递归买卖点为零，要求排查，并以一个月至少一个点作为异常线索。不能用数量配额制造信号。

## 两个独立原因

1. 旧线段实现把假设边界前后的特征元素统一包含合并。立讯精密真实5m第2/4笔对应区间55.63–55.32和55.79–54.88被吞成一个元素，第一处转折失去左支撑，后续30笔只生成一条候选线段。
2. 原5m接口尽管请求30日，实际只返回320根。没有一个月输入，无法对一个月输出作验收。

依据[第71课](https://chanlun108.cn/chanzhongshuochan108ke/71.html)边界包含说明，添加首反向笔破坏、反向第三笔或后续笔先突破终点、未先恢复原方向且前三笔重叠的有界分支，完整镜像条件见规则31。第三笔未破、触及、未确认都不能确认。普通特征分型及缺口二次确认保持原口径。同时拒绝非段内极值转折及方向与起终点不一致的段。还修复确认时间取后笔最终延伸端点的问题，按相同原始K线前缀首次确认几何回放，防止追加行情推迟旧信号时间。这里没有声称补齐第71课所有复杂分支。

5m改用新浪1023根接口，保留单一来源，不静默混源。原缓存备份；此次股票旧缓存全部被新源覆盖。日K底图与分钟来源不同，仍保留价差口径边界。

## 固定输入与接受的差异

旧320根输入原样保存在旧递归归档中。只修算法：1条未确认段变为4条段，其中3条确认；仍无递归买卖点。不能把补历史效果归因于该算法修复。

新的真实源固定输入存于tests/fixtures/luxshare_5m_20260930.json，含来源、时间、原始1023行行情。手工接受结果为13条确认段及1条候选段、L0两个中枢、两个S3：端点2026-09-11 14:20，观察时间2026-09-21 14:55；端点2026-09-29 09:55，观察时间2026-09-29 13:05。默认30日过滤后1008根，仍得到这两个信号。未形成L1的结构不补造。

固定黄金样本只升级版本，原几何预期不变；没有自动生成新预期。增加向上/向下边界包含、第三笔未突破及延迟突破/恢复原方向、未确认笔、已确认段方向及极值一致性，以及真实月度输入回归。真实点在观察时间之前不存在，观察时间当时及后续数据给出相同输出。已有随机历史追加稳定检查继续执行。
