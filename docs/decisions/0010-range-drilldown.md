# 0010：保留区间的多周期下钻

日期：2026-10-27。版本：4.2.0。

## 问题与决定

用户需要在日线分析一段走势时，直接查看同一区间的4h或其他更细周期。旧周期按钮重置默认日期，无法保持研究对象。

增加独立区间导航：两次点击K线、当前可见真实K线、或选中笔/段/中枢端点。支持逐层下钻与返回，加载成功才更新路径；失败保持原图，无数据仍能返回。父图视窗记录为真实K线覆盖日期，返回按此定位，不承诺像素级还原。显式focus覆盖日K基础行情自动聚焦；两图继续共享时间轴。

API沿用日粒度查询：起止交易日均包含，日内也按整日；周/月端点扩展到完整日历周期。只裁剪展示，后端继续全历史分析。下钻GET显式传入当前实际basePeriod/maxLevel，避免目标展示周期旧快照的不同设置使分析来源意外改变；普通查询仍恢复已有设置。

R01/R02/R03不改变：展示周期、计算基础、结构层级继续分开。不存在日K线段必然对应4h某一结构层的假设。A股4h一般一天一根，UI提示60m/30m更适合日内细节。源行情缺失不补造，按父图已知交易日提示缺口。

## 影响与验证

本版变更为导航及解释展示，按仓库保护要求升级RULE_VERSION；不改算法或行情，固定样本只更新版本号，几何预期不更新。前端测试覆盖逆向区间、同日分钟、周/月跨年/闰月、空白视窗与可选周期；浏览器用本地真实数据检查下钻请求、实际K线/MACD、连续返回、失败及空区间。运行前后用相同本地输入检查分析字段保持一致。完整后端测试、前端测试/构建及规则守卫纳入验收。

区间交互补充：选区使用独立点击层，避免图表库的500ms双击处理吞掉第二次点击。笔/段几何命中优先于同日期信号的兜底说明（直接点中买卖点标记仍优先解释该点）。业务表格样式限定在明细与解释面板，不能影响图表库内部table/td，否则padding会让画布与坐标产生偏移，选区和中枢覆盖层错位。显式区间导航不追加默认的右侧四根K线余量，返回恢复原可见交易日期。
