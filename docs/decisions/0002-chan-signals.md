# 0002：补齐可解释的缠论研究分析

规则版本：3.0.0；日期：2026-09-30。

用户明确要求按我们的理解补齐缺失缠论能力。v2只有基础几何和溯源，无法展示买卖点；本次实现分型强弱、MACD、同层中枢与趋势、背驰及一/二/三类点，前端标注与解释同步完成。

采用可选笔/线段结构尺度；不把它冒称为完整递归完成走势。规则F03/M01/T01/V01/P01/P02/P03及默认参数、边界与理论转载来源写在chan-rules第29节。局部衰减或单中枢盘整背驰不能冒充趋势一类点，突破不能冒充三类点。

保留基础centralZones几何；新增signalZones用于研究。相交的离开连接单元如果一直纳入旧包络，会把两个中枢的包络人为连在一起，无法识别方向趋势。因此在离开加首次外侧回试确认后，旧研究枢关闭并剔除连接离开单元，记录closedAt，下一枢从回试开始。关闭前末端包络允许变化，历史确认点不能用最终包络重算分类。形成时间和关闭时间必须计入信号最早可知时间。

图上默认按observedAt标点；端点视图明确为事后。候选与模型确认分开；不生成胜率，不自动交易。规则参数和输出加入归档/指纹，旧v2载荷先按原字段验证再迁移，保留原方案及间隔。

固定规则样本只把版本2.0.0显式更新到3.0.0，原分型/笔/段/基础枢几何预期未改。新增手算与结构样本独立验证MACD、强弱、完整两枢趋势背驰、一/二/三类点镜像、触边拒绝、预热/零轴、观察时间以及逐步追加确认点稳定性，禁止自动重录金样本。
