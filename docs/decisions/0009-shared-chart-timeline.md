# 0009：主图与MACD共用绘图时间索引

2026-10-16，规则版本4.1.2。用户再次反馈横排周期按钮切换后下面的图仍没有相应切换。本次纠正上一轮只检查接口和标题的不足，直接拦截隔离浏览器实际调用图表库的setData，记录渲染序列、可见时间范围及时间到像素的坐标。

## 已复现缺陷

主图的笔/段系列保留跨显示窗口的端点，这些时间也进入lightweight-charts的全局逻辑时间轴；MACD只拥有当前指标时间。原来两张图直接复制logicalRange，序号相同却对应不同日期。真实30m样本的主图可见范围混入8月28日11:30，MACD则从10月8日10:00开始；同一时刻横坐标相差约23.23px。日K相差约98.07px。原始K线和MACD数据确实已切换，但实际视窗并不对应。只核对API、标题和根数不足以发现该问题。

## 修复及边界

主图和MACD采用同一个有序时间集合：当前K线、指标、已开启的笔/段端点。没有K线或指标的时间只填whitespace，不填OHLC、指标值或成交量；不伪造行情、不改变笔/段几何。MACD柱、DIF、DEA和蜡烛统一按该集合索引。

首次视窗使用真实展示K线在共享时间轴上的索引，不能直接使用原始K线数组索引或fitContent把旧端点纳入展示范围。日K仍优先聚焦基础分钟行情覆盖日期；其他周期聚焦已加载K线。两图价格轴设置相同最小宽度，使时间对应到同一个水平像素；逻辑范围同步现以同一时间索引为前提。切换时清除旧hover内容；移除旧图时清理双向同步订阅。显示开关保留，不靠强制重挂整个组件掩盖状态问题。

本次只修正绘图，不改成笔、线段、买卖点成立条件、参数或行情源。R01/R02和R03的原始时刻及显示映射不变。因KLineChart及共享时间轴属于受保护展示实现，按约定升补丁版本，黄金几何预期不变、仅更新版本标签。

## 防回归与验收

新增独立时间轴单测，覆盖旧端点、日K聚焦、空输入；npm test及CI执行这些测试，时间轴模块加入变更守卫。浏览器验收必须同时核对实际主图/指标数据和同一时刻的横坐标，不能只断言标题更新。真实日K、30m、5m样本修复后两图可见时间一致、横坐标误差0px。另验缩放、拖动及周期反复切换；不会将规则版本升级解释为新增买卖点。
