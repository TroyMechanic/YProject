# 0012：周期按钮同步适配图表缩放

日期2026-10-27，版本4.3.1。

用户要求顶部周期按钮与下方滚轮缩放联动。此前按钮套用默认日期，渲染按全部记录/基础覆盖范围决定视窗，与滚轮维护的时间锚和尺度分离，可能看不到旧数据或出现过密/过大的K线。

显式点击按钮查询完整本地目标历史，读取当前实时可见中心K线（包含平移/缩放后的状态），映射至目标周期对应K线，并重置为可阅读密度。periodButtonRange与滚轮参数集中在wheelNavigation.ts：根数=max(ceil(width/24), min(120,ceil(width/12),实际逻辑跨度+4))，有锚点时居中；无锚点时最新真实K线位于90%横向位置，同时明确提示日期变更。空白不补造OHLC。

按钮请求成功且有真实行情才提交新周期/缩放；没有原位置但其他日期有行情时提示后定位最新本地数据，整个周期无行情/HTTP失败则保持原图。该策略只用于显式按钮，与滚轮缺锚点时停止切换的规则不同。

按钮清除下钻返回历史、旧focus和失败/手势锁，不重新挂载图层开关；点击当前周期同样重置缩放。后续滚轮使用当前周期，无旧周期回跳。查询和手动区间下钻保持自身日期语义。保持R01/R02/R03的展示周期/计算基础/结构层级区分；基础计算参数沿用当前实际设置。

按保护要求补丁升级版本，固定样本仅改版本字段，不更新算法几何预期。新增默认缩放边界测试，并用真实本地数据验证按钮切换后的canvas OHLC/MACD、时间锚、首个滚轮事件、重新点击、空缺提示和请求失败。


## 验收

112个后端测试、16个前端测试、前端构建及变更守卫通过。真实行情浏览器检查8种周期按钮：实际series OHLC与MACD逐项匹配相应API，两图横坐标差0px；选中时间居中保留；重复点击可重置极端缩放；切换后首个小幅滚轮不发新周期请求；图层和自动切换开关保留；503失败不修改周期/图形；800px窄窗口正常适配。原滚轮12阶段与手动区间11阶段回归通过。

8份全量快照输入哈希与分析字段（除analysis元信息）均无变化。证据存于docs/research/period-buttons-20261027-{render,comparison,wheel-regression,range-regression}.json。交互脚本scripts/verify_period_buttons.cjs使用本地真实历史，不生成模拟行情。
