# 0005：首段不能仅凭三笔重叠定向

状态：接受。规则版本：4.0.2。日期：2026-09-30。

## 缺陷与工程口径

通富微电的真实5m输入1008根、75笔，仅得到一确认段和一候选段、零点。初始三笔UP/DOWN/UP终点62.57/61.30/62.42，第三笔未超过第一笔高点；旧代码仅检查三笔交集便选为上行种子。该选择使初期下降走势失去可确认的首段边界，并被之后很远的高点纳入。

[第71课](https://chanlun108.cn/chanzhongshuochan108ke/71.html)讨论三笔方向不明时等待先破哪一端。结合已有段末端必须为方向极值的约束，项目采用冷启动条件：首次三笔严格重叠，第三笔沿同向严格超过第一笔终点。等价不接受；从左到右取首组符合条件者，此前片段不补造已确认段。这是截断行情初始化的工程口径，不宣称是原文唯一算法。

条件只作用于_find_initial_start；S02的反向候选包含等待和缺口二次确认不变。不改MACD、间隔、中枢或点的阈值，不按股票代码分支。
