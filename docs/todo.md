# TODO 功能清单

本文档只记录用户明确提出、想做但还没有实现的功能。

AI 不得根据自身判断擅自增加 TODO。讨论中的建议只有在用户明确决定纳入计划后，才能写入本文档。

## 缠论分析能力

- [ ] 顶分型 / 底分型强弱判断
  - 状态：待学习和明确判断规则。

- [ ] 笔的强弱判断
  - 状态：待学习和明确判断规则。

- [ ] 笔的概率与敏感度调节
  - 目标：通过不同的笔定义或口径调整识别敏感度，以应对不同的市场状况。
  - 可能对应：老笔、新笔、4K 笔、严格笔。
  - 状态：待学习并明确不同笔定义、概率含义、敏感度档位及适用市场。

- [x] 线段识别与图表标记
  - 目标：在已确认的笔序列基础上识别线段，并在前端标记线段起点、终点和方向。
  - 实现：采用特征序列、分型及线段破坏确认口径。
  - 已支持：显示/隐藏线段，点击线段时展示组成笔、确认状态、特征序列和判定依据。

- [x] 近 10 天细粒度 K 线
  - 目标：支持 4h、60min、30min、1min K 线，并继续计算和展示分型、笔、线段。
  - 数据范围：4h 默认查看和同步近 120 天；60min、30min、1min 默认近 10 天。
  - 已实现：A 股 1min、30min、60min 行情及按交易日聚合的 4h K 线。
  - 数据源限制：1min 当前最多返回最近约 320 根，不补造缺失历史数据。

- [x] 线段级中枢识别与图表标记
  - 目标：根据连续已确认线段的价格重叠识别中枢，并在图表中标记中枢区间。
  - 已实现：展示 ZD、ZG、DD、GG、中枢延伸状态和离开方向，支持图层开关，并可点击中枢查看组成线段与判定依据。
