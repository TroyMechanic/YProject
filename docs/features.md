# 项目功能文档

本文档记录 Chan Stock 当前已经实现的功能、使用方式和功能边界。它面向产品使用和后续需求讨论，不描述内部架构细节。

## 1. 项目定位

Chan Stock 是一个本地运行的股票 K 线缠论分析工具，当前用于验证：

```text
股票行情抓取
K 线本地存储
顶分型 / 底分型识别
笔生成
严格特征序列线段识别
线段级中枢识别
前端图表展示
规则解释
```

当前是 MVP，不是完整交易系统，也不提供投资建议。

## 2. 当前支持的股票范围

支持输入股票代码查询和同步数据。

当前默认规则：

```text
如果用户输入 6 位数字代码，默认按 A 股处理。
```

示例：

```text
002475 -> 002475.SZ
600519 -> 600519.SH
```

已验证常用代码：

```text
002475.SZ  立讯精密
DEMO       内置演示数据
```

也保留了海外股票代码能力，例如：

```text
AAPL
MSFT
```

但真实行情源可能受网络、接口可用性或限流影响。

## 3. 股票名称展示

前端标题会展示股票名称、股票代码和周期。

示例：

```text
立讯精密 002475.SZ 日K缠论分析
```

当前股票名称通过本地映射解析。未配置中文名的股票，会只展示代码。

## 4. K 线周期

前端按时间粒度从小到大排列并支持切换：

```text
1m
30m
60m
4H
日K
周K
月K
```

周期对应后端参数：

```text
minute1
minute30
minute60
hour4
daily
weekly
monthly
```

不同周期的数据、分型、笔、线段和中枢分别存储、分别计算。

切换到 4H 时，开始日期会默认调整为近 120 个自然日；切换到 60m、30m、1m 时，开始日期默认调整为近 10 个自然日。图表时间轴显示具体时分。

当前日内行情限制：

```text
仅支持 A 股代码
4H 由最多约 320 根 60m K 线聚合，通常可得到约 70 至 80 根
4H 每个交易日只保留一根，后续同步会覆盖同日盘中的未完成记录
1m 免费行情源最多返回最近约 320 根 K 线
30m / 60m 按近 10 个自然日内实际可得数据展示
4H 由同一 A 股交易日内的 60m K 线聚合
不补造行情源未返回的分钟数据
```

## 5. 行情同步

用户可以点击“同步”按钮获取股票行情。

同步流程：

```text
输入股票代码
选择开始日期 / 结束日期
选择周期
点击同步
后端抓取行情
写入本地 CSV
自动重新计算分型和笔
自动重新计算线段
自动重新计算中枢
前端刷新展示最新结果
```

当前同步不是纯增量同步，而是：

```text
按请求时间范围拉取数据
按交易日期 upsert 覆盖本地 CSV
对该股票该周期的本地 K 线重新计算分析结果
```

这样做的原因是最后几个分型和最后一笔可能随新增 K 线变化，全量重算更稳。

## 6. 本地数据存储

项目使用 CSV 作为本地数据存储。

K 线数据路径：

```text
backend/app/data/raw/{SYMBOL}_{PERIOD}.csv
```

分析结果路径：

```text
backend/app/data/analyzed/{SYMBOL}_fractals.csv
backend/app/data/analyzed/{SYMBOL}_bis.csv
backend/app/data/analyzed/{SYMBOL}_weekly_fractals.csv
backend/app/data/analyzed/{SYMBOL}_weekly_bis.csv
backend/app/data/analyzed/{SYMBOL}_monthly_fractals.csv
backend/app/data/analyzed/{SYMBOL}_monthly_bis.csv
backend/app/data/analyzed/{SYMBOL}_segments.csv
backend/app/data/analyzed/{SYMBOL}_weekly_segments.csv
backend/app/data/analyzed/{SYMBOL}_monthly_segments.csv
backend/app/data/analyzed/{SYMBOL}_central_zones.csv
backend/app/data/analyzed/{SYMBOL}_weekly_central_zones.csv
backend/app/data/analyzed/{SYMBOL}_monthly_central_zones.csv
```

日内周期也使用相同命名规则，例如：

```text
backend/app/data/raw/002475.SZ_minute1.csv
backend/app/data/analyzed/002475.SZ_minute1_fractals.csv
backend/app/data/analyzed/002475.SZ_minute1_bis.csv
backend/app/data/analyzed/002475.SZ_minute1_segments.csv
backend/app/data/analyzed/002475.SZ_minute1_central_zones.csv
```

CSV 适合当前 MVP 和本地研究使用。多用户、强并发、复杂查询不是当前目标。

## 7. 图表展示

前端图表展示以下内容：

```text
原始 K 线
顶分型标记
底分型标记
笔线
线段
中枢核心区间
最后一笔未确认状态
最后一段未确认状态
```

颜色使用 A 股习惯：

```text
上涨：红色
下跌：绿色
```

## 8. 鼠标悬浮 K 线信息

鼠标移动到某根 K 线上时，图表左上角会显示该 K 线信息：

```text
日期
开盘价
最高价
最低价
收盘价
涨跌额
涨跌幅
振幅
成交量
```

涨跌计算口径：

```text
涨跌额 = 当日收盘价 - 前一交易日收盘价
涨跌幅 = 涨跌额 / 前一交易日收盘价
```

如果没有前一根 K 线，则涨跌额和涨跌幅显示为 0 或空值口径。

## 9. 分型点击解释

用户点击图上的顶分型或底分型标记时，会展示分型解释卡。

解释内容包括：

```text
分型类型
分型日期
分型价格
三元素最高
三元素最低
左 / 中 / 右 三根标准 K 线
每根标准 K 线的原始 K 线来源
每根标准 K 线高低点
高点来源日期
低点来源日期
形成该分型的判断原因
```

注意：

```text
图上展示的是原始 K 线。
分型计算使用的是处理包含关系后的标准 K 线。
```

所以可能出现标准 K 线高点来自左侧某天，但标准 K 线日期归属右侧某天的情况。

## 10. 笔点击解释

用户点击笔线附近时，会展示成笔解释卡。

解释内容包括：

```text
起点分型
终点分型
方向
起点价格
终点价格
是否确认
顶底是否交替
标准 K 线间隔是否满足 minKlineGap
价格范围规则是否满足
最后一笔是否未确认
```

当前最后一笔会标记为未确认，因为后续 K 线可能导致修正。

## 11. 线段展示与点击解释

前端默认同时展示笔和线段：

```text
笔：较细的蓝色 / 橙色线
向上线段：较粗的红色线
向下线段：较粗的绿色线
已确认线段：实线
未确认线段：虚线
```

图表右上角提供“笔”和“线段”复选框，可以分别显示或隐藏。

点击线段附近时，会优先展示线段解释卡，包括：

```text
线段方向
起止日期和价格
组成笔数量
确认状态
破坏类型
标准特征序列
特征元素来源笔
元素间缺口状态
完整判定依据
```

当前线段采用严格特征序列方案，支持：

```text
前三笔价格重叠
特征序列包含处理
特征序列顶底分型
无缺口直接确认
有缺口反向特征序列二次确认
当前候选线段未确认
```

## 12. 中枢展示与点击解释

中枢使用连续至少三条已确认线段的严格价格重叠识别。

图表使用半透明琥珀色区域标记中枢核心区间：

```text
纵向范围：ZD 至 ZG
横向范围：第一条至最后一条组成线段
虚线边框：中枢仍在延伸或等待确认
实线边框：已经向上或向下离开
```

图表右上角提供“中枢”复选框，可以独立显示或隐藏。中枢区域的点击判定优先于线段和笔。

查询日期范围截断中枢起止时间时，图上的中枢区域会裁剪到当前已加载 K 线的首尾位置，解释信息仍保留中枢的完整起止时间。

点击中枢区域时展示：

```text
起止时间
ZD / ZG 核心重叠区间
DD / GG 全部组成线段范围
组成线段数量和序号
延伸中 / 向上离开 / 向下离开
完整判定依据
```

页面汇总区展示中枢数量，页面下方中枢表格展示最近 12 个中枢。

## 13. 重算功能

用户可以点击“重算”按钮重新计算当前股票、周期和日期范围内的分型、笔、线段与中枢。

可配置参数：

```text
标准K线最小间隔
```

默认值：

```text
1
```

该参数按合并后的标准 K 线数量计算，不按原始 K 线数量计算。

## 14. API 功能

同步行情：

```http
POST /api/stocks/{symbol}/sync
```

获取图表数据：

```http
GET /api/stocks/{symbol}/chart
```

图表响应包含：

```text
klines
fractals
bis
segments
centralZones
```

重新计算缠论结构：

```http
POST /api/stocks/{symbol}/chan/recalculate
```

健康检查：

```http
GET /health
```

## 16. 使用建议

推荐当前使用方式：

```text
先同步目标股票日K、周K、月K
用图表观察分型、笔、线段和中枢
点击异常或疑似错误位置查看解释
如果规则口径变化，先改规则代码和 docs/chan-rules.md
再重算相关股票和周期
```

如果后续功能增加，本文档需要同步更新，避免实际能力和说明不一致。
