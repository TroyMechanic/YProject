# 行情与缠论分析

首次打开或刷新页面时默认展示日 K。切换上证指数、立讯精密或通富微电，可查看本地行情。支持 1 分钟、5 分钟、30 分钟、60 分钟、4 小时、日、周和月周期。查询读取本地数据，同步获取行情，重算应用选定的成笔方案与最小间隔。

图表显示原始 K 线。分析按所选标的与周期的完整本地历史，依次合并包含关系、识别顶底分型、构造笔与线段。日期区间仅裁剪展示。笔统一使用蓝线，线段统一使用红线。满足成笔或成段条件后画实线。终点尚可延伸时，在当前终点标注“笔终点待定”或“段终点待定”。虚线仅用于尚未成立的候选结构；当前图表只绘制已经成立的笔和线段。图层可单独开关，点击结构可查看构成和确认依据。可开启滚轮自动切换周期，围绕鼠标所指的行情时间放大或缩小，也可导出当前视图。

## MACD 副图

MACD 副图使用当前周期完整本地收盘价历史，取 EMA(12) 减 EMA(26) 为 DIF，DIF 的 EMA(9) 为 DEA，柱值为 2 × (DIF − DEA)。按日期查询时同步裁剪行情和指标。主副图共用时间索引，正柱红色、负柱绿色。
