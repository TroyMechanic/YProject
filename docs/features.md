本文档记录 Chan Stock 当前已经实现的功能、使用方式和功能边界。它面向产品使用和后续需求讨论，不描述内部架构细节。

## 1. 项目定位

Chan Stock 是一个本地运行的股票 K 线缠论分析工具，当前用于验证：

```text
股票行情抓取
K 线本地存储
顶分型 / 底分型识别
笔生成
严格特征序列线段识别
线段级中枢识别
前端图表展示
规则解释
```

当前是 MVP，不是完整交易系统，也不提供投资建议。

## 2. 当前支持的股票范围

支持输入股票代码查询和同步数据。

当前默认规则：

```text
如果用户输入 6 位数字代码，默认按 A 股处理。
```

示例：

```text
002475 -> 002475.SZ
600519 -> 600519.SH
```

已验证常用代码：

```text
002475.SZ  立讯精密
002156.SZ  通富微电
DEMO       内置演示数据
```

也保留了海外股票代码能力，例如：

```text
AAPL
MSFT
```

但真实行情源可能受网络、接口可用性或限流影响。

## 3. 股票名称展示

前端标题会展示股票名称、股票代码和周期。

示例：

```text
立讯精密 002475.SZ 日K缠论分析
```

当前股票名称通过本地映射解析。未配置中文名的股票，会只展示代码。

常用股票提供“立讯精密”和“通富微电”快捷切换，保留股票代码自由输入。点击快捷按钮查询所选股票当前周期的已保存行情与分析，恢复该股票的规则参数，不自动复制另一只股票的数据。通富微电已同步日K与5m真实行情，并生成默认5m基础、最高L4的递归分析快照。

## 4. K 线周期

前端按时间粒度从小到大排列并支持切换：

```text
1m
30m
60m
4H
日K
周K
月K
```

周期对应后端参数：

```text
minute1
minute30
minute60
hour4
daily
weekly
monthly
```

不同周期的数据、分型、笔、线段和中枢分别存储、分别计算。

切换到 4H 时，开始日期会默认调整为近 120 个自然日；切换到 60m、30m、1m 时，开始日期默认调整为近 10 个自然日。图表时间轴显示具体时分。

当前日内行情限制：

```text
仅支持 A 股代码
4H 由最多约 320 根 60m K 线聚合，通常可得到约 70 至 80 根
4H 每个交易日只保留一根，后续同步会覆盖同日盘中的未完成记录
1m 免费行情源最多返回最近约 320 根 K 线
30m / 60m 按近 10 个自然日内实际可得数据展示
4H 由同一 A 股交易日内的 60m K 线聚合
不补造行情源未返回的分钟数据
```

## 5. 行情同步

用户可以点击“同步”按钮获取股票行情。

同步流程：

```text
输入股票代码
选择开始日期 / 结束日期
选择周期
点击同步
后端抓取行情
写入本地 CSV
自动重新计算分型和笔
自动重新计算线段
自动重新计算中枢
前端刷新展示最新结果
```

当前同步不是纯增量同步，而是：

```text
按请求时间范围拉取数据
按交易日期 upsert 覆盖本地 CSV
对该股票该周期的本地 K 线重新计算分析结果
```

这样做的原因是最后几个分型和最后一笔可能随新增 K 线变化，全量重算更稳。

项目使用 CSV 作为本地数据存储。

K 线数据路径：

```text

```

分析结果路径：

```text
backend/app/data/analyzed/{SYMBOL}_fractals.csv
backend/app/data/analyzed/{SYMBOL}_bis.csv
backend/app/data/analyzed/{SYMBOL}_weekly_fractals.csv
backend/app/data/analyzed/{SYMBOL}_weekly_bis.csv
backend/app/data/analyzed/{SYMBOL}_monthly_fractals.csv
backend/app/data/analyzed/{SYMBOL}_monthly_bis.csv
backend/app/data/analyzed/{SYMBOL}_segments.csv
backend/app/data/analyzed/{SYMBOL}_weekly_segments.csv
backend/app/data/analyzed/{SYMBOL}_monthly_segments.csv
backend/app/data/analyzed/{SYMBOL}_central_zones.csv
backend/app/data/analyzed/{SYMBOL}_weekly_central_zones.csv
backend/app/data/analyzed/{SYMBOL}_monthly_central_zones.csv
```

日内周期也使用相同命名规则，例如：

```text

```

CSV 适合当前 MVP 和本地研究使用。多用户、强并发、复杂查询不是当前目标。

## 8. 鼠标悬浮 K 线信息

鼠标移动到某根 K 线上时，图表左上角会显示该 K 线信息：

```text
日期
开盘价
最高价
最低价
收盘价
涨跌额
涨跌幅
振幅
成交量
```

涨跌计算口径：

```text
涨跌额 = 当日收盘价 - 前一交易日收盘价
涨跌幅 = 涨跌额 / 前一交易日收盘价
```

如果没有前一根 K 线，则涨跌额和涨跌幅显示为 0 或空值口径。

## 9. 分型点击解释

用户点击图上的顶分型或底分型标记时，会展示分型解释卡。

解释内容包括：

```text
分型类型
分型日期
分型价格
三元素最高
三元素最低
左 / 中 / 右 三根标准 K 线
每根标准 K 线的原始 K 线来源
每根标准 K 线高低点
高点来源日期
低点来源日期
形成该分型的判断原因
```

注意：

```text

```

所以可能出现标准 K 线高点来自左侧某天，但标准 K 线日期归属右侧某天的情况。

## 12. 中枢展示与点击解释

中枢使用连续至少三条已确认线段的严格价格重叠识别。

图表使用半透明琥珀色区域标记中枢核心区间：

```text
纵向范围：ZD 至 ZG
横向范围：第一条至最后一条组成线段
虚线边框：中枢仍在延伸或等待确认
实线边框：已经向上或向下离开
```

图表右上角提供“中枢”复选框，可以独立显示或隐藏。中枢区域的点击判定优先于线段和笔。

查询日期范围截断中枢起止时间时，图上的中枢区域会裁剪到当前已加载 K 线的首尾位置，解释信息仍保留中枢的完整起止时间。

点击中枢区域时展示：

```text
起止时间
ZD / ZG 核心重叠区间
DD / GG 全部组成线段范围
组成线段数量和序号
延伸中 / 向上离开 / 向下离开
完整判定依据
```

页面汇总区展示中枢数量，页面下方中枢表格展示最近 12 个中枢。

## 13. 重算功能

用户可以点击“重算”按钮重新计算当前股票、周期全部本地历史的分型、笔、线段与中枢。日期范围只裁剪展示，不截断持久分析上下文。

可配置参数：

```text
标准K线最小间隔
```

兼容方案默认输入为 1；独立分型方案生效值至少为 4。前端展示输入与实际生效值。

该参数按合并后的标准 K 线数量计算，不按原始 K 线数量计算。


## 17. 规则方案和计算溯源（v2.0.0）

- 提供兼容方案 `legacy` 和独立分型方案 `separated`。独立方案要求两个三元素不共用且中间留至少一根标准 K 线，推荐用于研究对照；首次后端默认保留兼容方案。
- 查询恢复该股票该周期已保存的设置。修改选择后需点击同步或重算才应用；页面分别显示待应用设置与当前图表实际设置。
- 同步请求可显式携带 `ruleProfile/minKlineGap`；省略则沿用已有设置，不再把自定义间隔重置为 1。
- 页面可展开查看缠论原则、版本、源数据范围、计算时间、批次和指纹，并导出当前视图 JSON。视图包含溯源；完整可复核结果在后端历史快照中。
- 新接口 `GET /api/chan/rules` 提供统一目录。图表与重算响应包含 `analysis`。
- 历史完整结果保存到 `backend/app/data/analyzed/runs/{SYMBOL}_{PERIOD}/{runId}.json`。当前快照是 API 权威结果，原有 CSV 继续提供可读导出。
- 原行情或代码/规则变化时查询自动全量重建；损坏快照报 409。已有旧 CSV 首次重建使用兼容默认值，无法猜测其原参数。
- 重算和同步全量分析，然后按日期裁剪图表，避免局部分析覆盖全量历史。
- 当前中枢明确为“线段重叠中枢”，离开方向不等于买卖点。

尚无自动备份/清理历史存档、多 worker 写事务和递归走势中枢。前端导出的裁剪视图不适用于完整快照校验脚本。


## 18. 分型、动能、背驰和买卖点（v3.0.0）

- 分型提供强/中/弱及三元素对照理由；笔与线段提供幅度、速度、成交量、MACD面积/峰值、相对动能和预热状态。
- 增加MACD副图，与主图横向窗口同步；DIF/DEA及柱值由真实本地行情计算。
- 可选择笔级或线段级研究中枢与点，调整面积阈值、零轴容差及MACD周期；同步/重算应用，查询恢复已保存设置。
- 显示研究中枢、关系及趋势摘要；原线段重叠中枢图层独立保留。
- 计算趋势/盘整背驰及局部动能衰减；按条件产生B1/B2/B3和S1/S2/S3。无条件则无点，不使用demo数据补点。
- 图上默认显示买卖点及候选，买红卖绿、候选橙色问号；可开关并切换确认时间与事后端点位置。点击标点查看原因、层级、中枢/背驰/父点引用及失效参考。
- 表格分别展示端点和最早观察时间；可展开背驰、中枢及关系明细。已确认不等于当前有效或盈利保证。
- 图表API增加 `indicators/signalZones/zoneRelations/divergences/tradingPoints/trend`；同步/重算请求支持 `signalLevel/divergenceRatio/zeroAxisTolerance/macdFast/macdSlow/macdSignal`。参数全部纳入批次指纹及历史快照。
- 可读导出增加指标、研究枢、关系、背驰、买卖点、动能、分型强弱CSV；API仍从单个提交快照读取。
- 规则版本3.0.0，旧快照校验后迁移并保留既有笔设置。日期窗口仅裁剪展示，保留全量结构与溯源。

当前信号使用同层笔/线段工程模型；尚未实现完整递归走势类型、递归级别扩张、严格走势级别买卖点和胜率回测。数据刷新仍需同步按钮，页面不是持续实时推送。


## 19. 结构递归与展示周期解耦（v4.0.0）

- 默认结构递归模式，原单周期模型保留为对照，可切换；展示周期与基础周期1m/5m/30m/60m独立，最大L层1—8可选。
- L0采用特征序列线段种子，后层仅由前层走势与中枢构造；确认和候选独立，不足层不补造。
- 各层计算研究买卖点；图上标基础周期与L层，可过滤层级。保留分钟端点/观察时间，日K可显示分钟来源点，不称其为日线级别点。
- 递归面板显示实际生成层、结构种类、几何时间、确认时间及枢/背驰；点击父结构展开组成和确认依赖，可一直查看到基础笔及原始K线序号。
- 来源范围、根数、批次及历史不足提示在图表上方显示。默认5m来自新浪最近最多1023根，默认30日；当前点数按实际结构生成，不回退旧模型补点。
- 新增 `/api/stocks/{symbol}/structure/chart` GET，以及 `/structure/sync`、`/structure/recalculate` POST。查询basePeriod/maxLevel可覆盖，省略恢复该展示周期已保存配置；基础MACD/笔参数在基础快照保存。
- 复合快照包含完整展示与基础输入及全部递归层，独立归档；API不从多个CSV拼输出。基础改变会自动重建，不污染旧单周期结果。

## 区间下钻（4.2.0）

在图表上方的“区间下钻”中，依次点击两根K线选起止，或使用当前可见区间。点击笔、线段、中枢后也可使用其起止区间。选择目标周期（如日K → 4h → 60m → 30m），点击“下钻分析”。

- 保留所选日期，不应用普通周期按钮的默认回看窗口；展示目标周期K线、MACD及该周期笔/段背景，递归基础周期和最大层数沿用已加载图表的实际值。下钻不把4h/60m等同于L0/L1，也不更改买卖点理论。
- 选区按日期包含两端整日；同日分钟端点也查看整个交易日，暂非精确到分钟的裁剪。周/月K端点扩展到完整日历周/月。
- 分析仍基于完整本地历史，不拿截断片段重新起算。路径栏显示来源周期、请求日期；“返回上一层”恢复父图的查询区间和可见日期。返回不保证相同像素缩放或空白边距。
- 无数据也保留路径与选区，允许同步或返回；部分覆盖时显示父图已知交易日缺失数。请求失败保留原图。没有自动同步或demo回退，分钟源可能不提供较早历史。普通查询/换股票/普通周期切换开始新浏览路径。
- A股4h为一个交易日的四小时交易时段，通常一天一根；看日内细节应选择60m、30m等。
- K线与MACD继续共享时间轴。此版只增加导航；同输入、同参数的分析结果不变。


## 滚轮自动切换周期（4.3.0）

默认开启“滚轮自动切换周期”，可关闭以仅放大缩小现有K线。在K线或MACD绘图区滚轮放大，达到阈值后自动进入更细周期；缩小优先回到刚才的周期。自动路径为月K → 周K → 日K → 60m → 30m → 5m → 1m；4h与日K的A股交易时长相同，自动路径跳过4h，手动4h仍可进入60m并返回4h。

- 鼠标所指K线的时间锚与横向位置保留；日/周/月锚展开到其日历区间内最后一根可用子K线，分钟锚映射到覆盖该时间的K线。更粗周期只能精确到包含该时刻的K线，无法保留不存在的子K线。
- 滚轮视窗保留分钟边界，不采用手动选区“端点整日”的扩展方式。加载完整本地展示历史便于继续平移和缩小，视窗单独定位，计算仍使用完整历史。
- 没有鼠标锚点对应行情时保持原周期及原图；提示缺失位置和目标周期本地可用范围。HTTP失败同样保留原图。同方向、同锚点日期的重复缺失请求会被抑制，换日期或同步后可重试。
- 连续滚动每个手势最多切换一级，放大与缩小采用不同阈值防止抖动；图层开关和基础分析参数保留。选择起止区间、操作价格轴及解释面板时不触发自动周期切换。
- 不自动同步行情，不用日K反推分钟数据。图旁直接显示切换和数据不足提示；部分父图日期缺失时显示覆盖警告。


## 周期按钮与图表缩放联动（4.3.1）

顶部1m/5m/30m/60m/4H/日K/周K/月K按钮同时切换图表数据与缩放尺度，主图和MACD同步。优先保留当前可见区域中间的K线时间；数据充足时约12px/根（最多120根逻辑跨度），历史很少时不让K线变成巨柱（约不超过24px/根，保留空白）。重复点击当前周期也会重新适配缩放。

按钮显式切换后重置滚轮返回路径、旧选区聚焦和重复失败锁定，之后滚轮从当前周期继续工作；图层开关与自动切换开关保持。仅点击按钮不自动下钻到另一个周期。

顶部按钮不再强制套用旧的120/30/10天回看窗口，改查完整本地目标周期历史。没有原位置对应行情时，明确提示并定位最新本地行情；全部无数据或请求失败保留原图。查询表单仍可手动限制日期；同步接口省略日期时的行情源默认回看长度不变。按钮切换不会自动联网同步，也不会把旧行情称为实时行情。
